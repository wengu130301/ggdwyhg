守夜说明 / 制作说明

Procedural gothic vignette · 单人探索 Demo

故事：汩汩古堡曾是一座午夜动物收容所。守钟奶奶温婆婆照料着鹿、犬、鸦、猫与雾中的来客。可每当午夜钟声响得不对，住客们便会躁动起来。你是新来的夜班看守，需要探索三个房间与一条长廊，靠纸条、旧照片、钟声次数和她的矛盾话语，判断她今晚是否还清醒，并撑到黎明。

操作：WASD 移动；鼠标环顾；Shift 慢走并降低被发现率；E 互动；Q 掩住／点亮手中的守夜烛；Esc 暂停。靠近桌、门、钟、抽屉、照片、纸条或奶奶，中央出现提示时按 E。

安全边界：本作为轻量氛围微恐。没有血腥、尸体、肢解、暴力、攻击老人、自伤、性内容或宗教敏感表达。动物不会撕咬、流血或接触玩家，只会造成“镇定值”压力。“后宫”仅为动物收容所的戏称。受控突脸不超过 0.5 秒、无扭曲人脸、无超大音量，默认每夜最多一次，可在设置中关闭；蜘蛛只出现在墙角，最多 8 只，不爬镜头、不覆盖画面中央。

技术：Three.js 通过 CDN import map 引入；场景、材质纹理、旧照片、粒子、蜘蛛网、音效全部程序化生成；无外部模型、贴图或音频文件。存档使用 localStorage。

版本 1.0 · 单文件原型 · 适合约 17 岁及以上的轻度微恐体验。若屏幕光敏不适，请使用“温和”模式或关闭突脸。

Epilogue · 第六个黎明

钟声睡去之后

铜摆停在三下短钟之间。窗外的巨像缓缓转过身，像一座终于记起自己职责的雕像，重新融进晨雾里。

阿鹿坐在长廊尽头数门；灰牙把披风铺在壁炉边；黑羽落在最高的窗棂上；滴答的尾巴终于不再像钟摆；雾角在门口化成一小团白雾。

温婆婆把青蓝色别针别回衣领，问你：“天亮以后，还愿意留下来吗？”

你收起笔记本。古堡不再是困住谁的钟，而是一座真正的午夜收容所。那些被钟声借走的耳朵，都慢慢回来了。
